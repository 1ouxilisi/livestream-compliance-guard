# 案例：直播电商合规守卫（MCP 服务）

> 自建工程项目（personal portfolio project），非付费客户案例。文中所有数字均来自本仓库内可复跑的报告：`reports/BENCHMARK.md`、`reports/LLM_EVAL.md`、`reports/MODEL_CROSSCHECK.md`、`reports/PERF.md`，以及 `pytest` 输出。

## 一、问题

直播带货里一句话就能踩线——"最/第一/保真/升值/加微信/养生辟邪"——后果是警告、断播、扣分、罚款、清退。数字人和 AI 主播 7×24 小时说话，人工盯不住；等平台下通知，损失已经发生。

现有方案两头都不好使：纯词表 + 正则绕不过谐音、拆字、emoji、斜杠阻断；纯 LLM 不可解释、没有硬底线、每句都烧钱。

## 二、方案

做成一个可被任意 agent 调用的 **MCP 工具**，而不是又一个网页。6 个工具：`scan_text`、`scan_livestream`、`compliance_rules`、`safe_rewrite`、`scan_smart`、`rewrite_smart`。

核心是**两层结构**：

- **规则层**：确定性、可解释、零第三方依赖，是硬底线；
- **LLM 层**：只做语义补充（谐音/拆字/emoji/近义暗示）与自然整句改写；无 key、超时、超预算、返回脏数据时自动降级为纯规则，返回 `mode` 与逐命中 `source`。

规则源是语言中立的 JSON：核心包 v1.5（14 规则 / 16 替换，其中翡翠规则以 `industry:jadeite` 隔离内置）＋ 食品、化妆品两个插件包（各 3 规则 / 8 替换），聚合 20 规则 / 31 替换，Python 与未来 TS/Cloudflare 运行时共用同一份词库。

## 三、技术难点与处理

1. **绕过对抗**：两层归一化。等长层处理全角、英文大小写、常用繁→简（识别 `１００％`、全角联系方式、`全網第一`）；紧凑层剔除空格、中点、emoji、斜杠、竖线、反斜杠（拦 `最 好`、`NO·1`、`微❤️abc12345`、`最/好`），同时保留中文标点与停顿不跨句合并，避免把两句正常话拼成一条违规。
2. **序数消歧**：`第一步`、`第一款` 放行；`销量第一`、`第一名` 仍判 high。
3. **导流正则**：要求词首信号＋号码含数字，英文 `voucher` 这类正常词不误报。
4. **改写闭环**：替换后立即复检；紧凑层命中的位置也能映射回替换，保证"改完还是干净"。
5. **工程化**：租户配额与 token 双维计量、ApiKey→租户/角色映射骨架、审计 JSONL（默认关闭、可脱敏）、误报漏报反馈记录与 CSV 导出、stdio 与 Streamable HTTP 双协议 ＋ 可选 Bearer。

## 四、结果（全部可复跑）

| 指标 | 结果 |
|---|---|
| 单元测试 | `pytest` 232 项全绿 |
| 规则层评测 95 条（良性 40 / 对抗 55） | 高危检出 100%，干净话术误报 0% |
| LLM 在线快照（主力 Qwen3-14B） | 73/73（语义召回 14/14、红队阻断 22/22、LLM 零误报 37/37） |
| 双模型交叉 34 条 | Qwen3-14B 34/34；DeepSeek-V3 33/34 |
| 规则层单句延迟 | P50 3.25 ms，P95 9.89 ms，145 句/秒（本机测量，非生产 SLA） |
| 批量 120 条 | 总耗时 495 ms，单句均摊 4.13 ms |

在线 LLM 结果随模型版本与账户余额波动，以 `reports/LLM_EVAL.md` 最新快照为准。

## 五、怎么验证（约 3 分钟，零依赖）

```bash
python server.py --selftest                      # 规则核心自测，不装依赖
python scripts/demo_walkthrough.py --offline     # 离线走查：检测→命中→改写→复检
python -m pytest -q                              # 232 项
```

截图见 `docs/assets/demo-zh.png`（中文界面：输入话术 → 风险等级 → 命中词 → 法规依据 → 改写建议）与 `docs/assets/demo-en.png`。

## 六、能力边界（明确不做）

- 不做 ASR/OCR：只接收已转写的文本，输入源用可插拔协议（已备内存桩，未接真实 ASR 上游）。
- 不构成法律意见，不承诺"过审"或固定准确率；输出是风险提示与改写建议。
- 规则会滞后于监管与平台规则更新，重要场景仍需法务复核。

## 七、能承接什么

- 定制行业词库与新平台规则（医疗器械、教育培训、金融理财等需逐条核实法条后再做）；
- 私有化部署：Docker、反向代理、内网部署、与现有客服/数字人后台对接；
- 接入你的 ASR、MCP 客户端、内容审核流水线；
- 按项目或按天承接，沟通与交易仅走 Fiverr / Upwork 等第三方平台站内。
