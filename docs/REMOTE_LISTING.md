# 国内远程渠道 · 服务文案草稿（云沃客 / 电鸭等）

> 公开文案草稿，能力描述与交付边界可对外使用；**定价金额、成交口径、渠道台账不写进本仓**（见私有归档）。
> 本文件不出现虚构客户名、评价、销量或"包过审 / 法律背书"承诺；联系方式与收款一律在平台站内完成。

## 1. 一句话定位

直播电商话术 / 短视频文案 / 商品标题 / 客服回复的**发布前合规筛查**：广告法极限词、虚假宣传、升值投资承诺、医疗功效、迷信伪科学、站外导流；返回风险等级、命中词、依据提示与合规改写建议。规则核心确定性可复核，可选 LLM 语义层补充谐音 / 拆字 / emoji / 近义暗示，无模型 key 时自动降级为纯规则。

## 2. 能力与交付物

- **单条检测**：风险级别 `high / medium / low / clean`、命中词与类别、依据提示、修改建议。
- **批量过稿**：整场直播 / 一批文案逐段扫描，输出时间线、高风险计数、待整改清单。
- **合规改写**：规则层命中词安全替换并复检；可选 LLM 自然整句改写，改写后由规则层复检，未通过不采用。
- **词库定制**：按行业 / 平台补充规则词与替换建议，插件化挂载，不改核心引擎。
- **工具接入**：以 MCP（stdio / HTTP）或 Python 模块形式接入现有直播后台、数字人系统或审核流程。

### 覆盖范围（当前版本）

- 平台：抖音、快手、视频号小店、淘宝直播。
- 行业：通用、翡翠 / 珠宝、食品 / 保健食品、化妆品。
- 规则规模：20 条规则 / 31 条替换建议（核心通用 + 食品 + 化妆品插件）。

### 可复现的能力佐证

- 离线规则评测 75 条：整体 75/75，高危样本检出率 100%，干净样本误报率 0；146 项单元测试通过（见 `reports/BENCHMARK.md`、CI）。
- 在线 LLM 语义层快照 40/40（语义召回、红队阻断、零误报）；属配 key 后手动复跑的在线快照，随模型版本与账户余额波动，**不作为离线门禁**（见 `reports/LLM_EVAL.md`）。
- 样例产物：`samples/` 内含整场合规周报（HTML）、批量明细 CSV、改写前后对照、反馈导出样例；离线演示 `python scripts/demo_walkthrough.py --offline`。
- 性能参考：规则层单句平均约 1.8ms，吞吐约 556 句/秒（见 `reports/PERF.md`）；规则核心零第三方依赖。

## 3. 服务档位（结构 only — 价格另议）

| 档位 | 范围 | 交付物 |
|---|---|---|
| 排查 | 买家提供一批话术 / 文案 / 标题 / 回复 | 风险报告（HTML / CSV）、命中点 + 依据提示、改写对照表 |
| 定制 | 排查 + 单一行业 / 平台词库调整，批量复核一批稿件 | 上述 + 插件词库、改写前后 CSV、待复核清单 |
| 接入 | 定制 + MCP 服务（stdio / HTTP）接入、可选 LLM 层接线、样例报告 | 上述 + 可运行服务配置、样例报告、README / 运行说明、测试与评测用例 |

## 4. 对外边界（必须保留）

- 仅为合规风险提示与改写建议，**不构成法律意见**，不等同平台审核判定，不为商品资质 / 真伪背书。
- 不核验营业执照、备案、注册 / 证书真伪；不做语音（ASR）与图像（OCR）识别，当前只处理文本。
- 高危命中须由人工复核后再发布。
- 暂不覆盖：医疗器械、药品、金融理财、保险、教培、酒水、跨境 / 进口商品、英文及 TikTok Shop / Amazon Live 规则。
- 规则层存在固有漏报 / 误报；在线结果随模型版本与账户余额波动。
- 强监管行业的最终合规结论，由买家自行经法务或平台规则中心复核。
