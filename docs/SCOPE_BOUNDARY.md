# 承接范围与能力边界（Scope & Boundary）

> 明确本工具**能做什么、不能做什么、哪些必须转人工**，避免把工程化风险筛查误当成法律背书或平台审核结论。

## 1. 工具定位

- 本工具是直播电商话术的**辅助合规筛查与改写建议**：规则硬底线 + LLM 语义补充，输出风险级别、命中点、依据提示与改写建议。
- 它**不是**法律意见、不是律师合规意见书、不是平台审核结果，也不对商品本身的真实性、资质或质量作背书。
- 最终是否上播、如何表述，由商家 / 主播自行负责；**high 级别命中必须经人工复核后再使用**。

## 2. 当前覆盖范围

| 维度 | 已覆盖 |
|---|---|
| 行业 | 综合（general）、翡翠珠宝（jadeite）、食品/保健食品（food）、化妆品（cosmetics） |
| 平台 | 抖音、快手、视频号、淘宝 |
| 风险类型 | 绝对化用语、虚假误导、升值投资承诺、医疗功效宣称、迷信伪科学、站外导流/违规交易、行业专项话术、诱导性叫卖 |
| 输出 | 风险级别（clean/low/medium/high）、命中词与依据、改写建议、批量分段检测 |

## 3. 明确不承接 / 弱覆盖（须转人工或专业渠道）

以下事项**不在当前规则层能力内**，工具最多给出提示，不得据此下结论：

1. **药品、医疗器械、特殊医学用途配方食品**：注册备案、适应症、说明书口径属强监管领域，需专业法务与药监口径审核。
2. **金融、理财、保险、证券、收藏品投资**：收益承诺、资质牌照、风险揭示由持牌机构与专门规则约束，本工具不承接。
3. **保健食品备案/注册范围识别**：保健功能声称是否在获批范围内、"本品不能代替药物"提示是否齐备，规则层不核验资质。
4. **资质证照与真伪**：营业执照、商标、授权书、鉴定证书、检测报告的真伪与有效期，规则层无法在线核验。
5. **价格、税务、资质门槛**：原价/成交价是否真实、税费、店铺经营范围与准入资质，属经营合规与平台入驻审核范畴。
6. **跨境/进口商品合规**：报关、检疫、进口许可、外文标签翻译合规等，当前未覆盖。
7. **证据充分性**："第一""冠军""热销"等是否有可核验第三方数据，工具只提示风险，不判断举证是否成立。
8. **母婴、特殊人群、医疗美容机构**等强敏感场景：建议直接转人工与专业顾问。

## 4. 技术能力边界

- **规则层**：基于归一化子串与正则匹配，存在**漏报**（未收录的新说法、变体、谐音拆分、图文/口播未转写部分）与**误报**（合规语境中命中关键词）。
- **LLM 语义层**：仅作规则层的补充召回，不能降低或撤销规则命中；模型可能超时、返回脏数据或不可用，此时自动降级为纯规则结果（`rules_only`）。LLM 结论同样需人工复核。
- **输入范围**：只处理文本（话术/字幕/商品文案）；图片、视频、语音、弹幕、评论区内容不在当前检测范围。
- **不做事实核验**：工具判断"这句话违规风险高"，不等于"这个商品是假的"；反之放行也不代表内容必然合规。

## 5. 人工复核义务（建议固化为流程）

1. **high 命中**：上播前必须人工逐条复核，必要时咨询执业律师或平台规则中心；不得仅凭工具放行。
2. **medium/low 命中**：建议运营或合规岗确认话术，按改写建议调整。
3. **改写建议**：LLM / 规则给出的改写文本需商家结合商品真实信息确认；复检仍含违规词的候选会被标记 `needs_human_review`。
4. **敏感行业咨询**：涉及第 3 节任一类别，转对应专业顾问，不使用本工具结论对外承诺合规。

## 6. 词库与依据维护流程

1. 新增/修改命中词，须在规则库注明**依据来源**（法条或平台规则名称），并 `bump meta.version`。
2. 同步补充离线评测用例（对抗 / 良性），保证检出率不下降、误报不上升。
3. 法律更新或平台规则改版后，由法务 / 商家核验条款序号与表述，再更新对照表 `COMPLIANCE_MAPPING.md` 的复核状态。
4. 未完成法务复核的依据，对外材料中保留"待复核"标注，不得包装成已认证结论。
