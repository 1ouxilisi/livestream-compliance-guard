# 规则依据对照表（Compliance Mapping）

> 本表把规则库每条规则与其对应的法律 / 法规 / 平台规则依据逐条对齐，供产品说明、客户问询与后续法务复核使用。
>
> **定位与免责**：本工具为直播话术**辅助风险筛查与改写建议**，不构成法律意见，不替代执业律师出具的合规结论，也不等同于各平台的审核判定。表中依据来自规则库 `law` 字段；**条文序号、表述与平台规则版本均需经法务或各平台规则中心复核后再对外引用**。

## 复核状态图例

| 标记 | 含义 |
|---|---|
| `待法务复核` | 依据名称已在规则库标注，但条文序号 / 原文表述尚未对照官方最新文本核验 |
| `待平台复核` | 依据为平台内部规则，规则名称待对照商家后台最新规则中心页面并补官方链接 |
| `规则层限制` | 该问题超出规则层能力（资质、备案、真伪等），需交 LLM 语义层或人工 |

## 四、复核与引用要求

1. **对外引用前必须复核**：上表法律条文序号、原文表述以国家法律法规数据库（https://flk.npc.gov.cn ）最新公布为准；平台规则以各商家后台规则中心最新版本为准，并补充官方规则链接。
2. **规则层不判断资质真伪**：商品是否取得对应注册/备案、证书是否真实、宣传是否有可举证依据，规则层无法核验，统一标记为需人工或专业渠道确认（见 `SCOPE_BOUNDARY.md`）。
3. **词库变更需留痕**：新增/修改命中词须在规则库注明依据来源，bump `meta.version`，补充对应评测用例，再随版本发布。
4. **免责口径**：任何对外材料中，本工具结论均应表述为"风险提示/建议修改"，不得表述为"已合规""平台认可""法律背书"。
