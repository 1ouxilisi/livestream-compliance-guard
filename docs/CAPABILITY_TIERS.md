# 能力分档清单（Capability Tiers · 上架口径）

> 把当前代码能力分成三档：**A 可写进 Gig 卖点**、**B 骨架/可选只能如实标注**、**C 不可承诺/不承接**。
> 判定依据是 0.9.0 实际代码、测试与评测快照；对外文案只能引用 A 档事实，B 档须带“可选/骨架”限定，C 档不得出现在卖点中。
> 数字以 `reports/BENCHMARK.md`、`reports/LLM_EVAL.md` 与 `pytest -q` 最新结果为准；发布前需复跑回归。

## 判定口径

- **A 档**：工程内已闭环、有测试或离线评测支撑、确定性可复现。
- **B 档**：协议/内存骨架已落地，但缺外部服务、持久化、真实样本或法务复核；只能作为“可扩展/可选能力”描述，不能当成品承诺。
- **C 档**：属外部依赖（法律、资质、真实识别服务、生产基础设施、商业成交），代码单方面无法消除，不得对外承诺。

## A. 可对外写进卖点（已闭环 · 有测试/评测支撑）

### A1. 确定性规则检测（纯规则，零第三方依赖）
- 覆盖方向：广告法极限词、虚假/误导宣传、升值投资承诺、医疗功效宣称、迷信伪科学、站外导流/诱导交易。
- 输出四级风险 `high / medium / low / clean`，命中词带类别、依据提示与修改建议；规则命中可解释、可复核。
- 两层归一化：等长层（全角转半角、英文小写、常用繁简一对一映射）＋紧凑层（剔除空格/零宽/emoji/分隔符阻断变体）；“第一”序数消歧（第一步/第一款等不判排名）。
- 评测：规则层离线 **95/95 通过**（良性 40、对抗 55），高危检出率 **100%**，干净样本误报率 **0%**（见 `reports/BENCHMARK.md`）。

### A2. 六个 MCP 工具与两种传输
- 工具：`scan_text`（单条纯规则）、`scan_livestream`（整场批量）、`compliance_rules`（生效词库查询）、`safe_rewrite`（规则替换＋复检）、`scan_smart`（规则＋LLM 融合）、`rewrite_smart`（LLM 改写＋规则复检回退）。
- 传输：stdio 与 Streamable HTTP；可作为 MCP 工具接入任意支持 MCP 的 agent/客户端，也可作为 Python 模块直接调用。
- 批量过稿：整场直播/一批文案逐段扫描，输出时间线、高风险计数与待整改清单。

### A3. 规则硬底线 ＋ LLM 可选降级
- 规则永远先跑且不可被 LLM 降低；最终严重度取规则与 LLM 的最高值。
- 无模型 key、超时、脏返回或超预算时自动降级纯规则（`mode=rules_only`），服务不中断；融合时 `mode=rules_plus_llm`。
- LLM 不可用或改写后复检仍违规时，不采用候选，保留规则版并标记需人工复核。

### A4. 工程质量与可复现
- 单测 **219 项全绿**，ruff 全仓通过；规则词库一致性校验通过，wheel 打包解包断言词库随包打入。
- 规则词库插件化：核心包 14 条规则/16 条替换，化妆品、食品为可插拔插件（各 3 条/8 条替换），全局 20 条规则/31 条替换。
- 覆盖平台：抖音、快手、视频号小店、淘宝直播；覆盖行业：通用、翡翠、食品/保健食品、化妆品。
- 可离线演示：`python scripts/demo_walkthrough.py --offline`；规则核心不依赖网络与模型 key。

## B. 骨架 / 可选能力（只能如实标注，不可当成品承诺）

> 以下协议或内存骨架已在代码中落地并有测试兜底，但缺外部服务、持久化、真实样本或法务复核；对外描述必须带“骨架 / 可选 / 本地内存 / 单进程”限定。

### B1. 身份与 Key 映射 / 角色门禁骨架（`lcg.identity`）
- 已落地：`ApiKey` → 租户 / 角色 / 操作人映射，停用与最近使用记录；默认进程内存，可选本机 SQLite 持久化后端（`LCG_IDENTITY_DSN`，落盘重启不丢）。角色动作矩阵：`viewer` 只读扫描 / 查规则，`operator` 追加改写，`admin` 预留管理动作；工具入口按动作校验，越权抛 `PermissionError`；Key→角色可经 `LCG_KEY_ROLES` 映射；非法角色 / 动作登记即报错。
- 未实现：用户注册 / 登录、密码哈希、API Key 签发与轮换、对接外部身份服务；权限为单进程薄门禁，不替代外部鉴权，不跨进程共享。

### B2. 配额与计量骨架（`lcg.tenant`）
- 已落地：调用次数 + token 双维度配额预检，未注册 / 停用返回 403、次数 / token 超额返回 429；用量快照；内存或可选本机 SQLite 后端；回填异常不阻断主流程。
- 未实现：外置持久化计量、账单 / 套餐对接、单价配置化、按 token 配额强制停用、跨实例配额共享。

### B3. 审计 / 反馈本地留痕（`lcg.audit` / `lcg.feedback`）
- 已落地：检测 / 改写事件本地 JSONL 或本机 SQLite 留痕，可选脱敏；反馈记录与 CSV 导出；`audit.query` / `feedback.query` 按行业 / 平台 / 类型 / 风险 / 操作人 / Key 过滤；审计事件带 `operator` / `key_id`。
- 未实现：检索界面、留存策略、跨进程 / 跨实例共享、外置数据库或对象存储、备份归档。

### B4. 缓存协议骨架（`lcg.cache`）
- 已落地：`CacheStore` 协议与 `InMemoryCache`，可选 TTL、访问时惰性过期；线程安全。
- 未实现：Redis / 外置 KV / 分布式缓存、多实例缓存共享；当前进程内缓存重启即清空。

### B5. 输入源与识别适配器协议（`lcg.ingest` / `lcg.sources`）
- 已落地：把上游 ASR / OCR / 字幕 / 表格产出的异构文本片段归一为检测契约；`Recognizer` 识别适配器协议与内存桩。
- 未实现：不做真实语音识别（ASR）与图像文字识别（OCR）；媒体负载到文本的识别由外部服务承担。

### B6. 强监管行业占位插件
- 现状：医疗、金融理财、教育培训、酒水、跨境进口为 `rules/plugins/_*.json` 占位骨架，`rules` 保持为空、`pending_legal_review=true`，未提供实词库；底稿内已列待核风险类别、候选法规方向（`candidate_sources`，条号/链接留空 `to_verify`）与上线前复核清单（`review_checklist`），经法务逐条核验后才可回填 words/patterns 并去除文件名前缀。
- 注意：通用 / 食品 / 化妆品 / 翡翠词库的法条与平台规则仍标注“待法务 / 待平台复核”，未完成逐条核验。

### B7. LLM 语义层（可选依赖）
- 已落地：OpenAI 兼容客户端，主备模型配置；谐音 / 拆字 / emoji / 近义暗示等语义补充；失败自动回退规则。
- 限定：在线快照 **73/73**（语义召回 14/14、红队阻断 22/22、零误报 37/37）为配 key 后手动复跑；双模型交叉 34 条 `Qwen3-14B 34/34`、`DeepSeek-V3 33/34`（1 条指令覆盖分歧 r12）。结果随模型版本与账户余额波动，**不是离线 CI 硬门禁**；使用需提供模型 key 与余额。

## C. 不可承诺 / 不承接（外部依赖，代码无法替代）

> 以下事项属法律、资质、真实服务或生产基础设施范畴，本仓库代码单方面无法闭环；不得出现在 Gig 卖点或交付承诺中。

- **C1. 法律与合规结论**：不提供法律意见、律师合规意见书、平台审核结论；不承诺“包过审”“平台认可”“法律背书”；最终是否上播由商家 / 主播负责，high 命中必须人工复核。
- **C2. 资质与事实核验**：不核验营业执照、备案、许可证、证书真伪；不判断“第一 / 冠军 / 热销”等宣传是否有可举证依据；不担保商品真实性、质量与来源。
- **C3. 真实媒体识别**：不做语音（ASR）、图像文字（OCR）、视频、弹幕、评论区原始内容识别；只处理已转写文本。
- **C4. 生产基础设施**：不含生产服务器、域名、TLS 证书、支付结算、SLA 保障、多实例水平扩展、高可用与灾备；这些由部署方在目标环境落地。
- **C5. 法务与官方规则复核**：法条序号、原文表述、平台规则版本需经执业律师或各平台规则中心核验；强监管行业（医疗 / 金融 / 教育 / 酒水 / 跨境）规则不在本仓库内闭环。
- **C6. 商业成交与售后**：不保证检出率达到某个商业指标、不替代客户验收；不承接成交纠纷、退款、投诉处置；真实客户场景命中率需用真实样本另行验证。
